# PDF export examples

The PDFs here are the default monochrome ones (`p` in the TUI: black and gray
for monochrome printers). Generated by `cargo test write_example_pdfs -- --ignored` from the corner
cases in `src/export/pdf.rs` (`tests::corner_cases`). Regenerate and look at
them after changing the layout; the dates inside change on every run.

| File | What it shows |
|------|---------------|
| `00-showcase` (also in color, in `color/`) | A nice-looking everyday card rather than a corner case: labels, due date, headings, lists, quote, table, matrix, checklist, code |
| `01-empty-card` | No title, description or checklist |
| `02-very-long-title` | Title wrapping over many lines |
| `03-unicode-and-missing-glyphs` | Umlauts, symbols, glyphs the fonts lack (`?`), tabs, control characters |
| `04-unbreakable-words` | Words wider than the page in text, list, quote and inline code |
| `05-wide-table` | Ten columns: padding and type shrink before words are broken |
| `06-long-table-repeats-header` | 150 rows over several pages with the header repeated |
| `07-heading-hierarchy` | Level 1-3 sections kept together where they fit a page |
| `08-lists-and-quotes` | Nested lists, numbering, nested quotes |
| `09-code-blocks` | Over-long code lines wrapped, a block taller than half a page, an unterminated fence |
| `10-checklist-page-break` | Checklist moved to a fresh page as a unit |
| `11-many-labels` | Label chips wrapping over rows, due date |
| `12-markdown-oddities` | Unclosed markers, header-only and ragged tables, raw HTML |
| `13-emphasis` | Bold, italic and bold italic, in paragraphs, lists, quotes and table cells |
| `14-matrix` | Matrix tables (empty top-left cell): open corner, bold first column, heavy label separators, column lines from 4 content columns, row separators above 7 rows, wrapping labels, header-only and one-column matrices, a long matrix over several pages |

`color/` holds only `00-showcase` in color (`P` in the TUI, `--style color`).
